# Folio I — Heather-to-Collin review concept (NOT APPROVED)

Open [the standalone HTML review](folio1-atlantic-review.html) as a downloaded file in a browser. It is **not integrated into the Moby-Dick website** and not an authenticated route overlay. It can display the two historical source sheets **if external image hosts load**, or let you choose a locally downloaded Collin image. Note that GitHub's normal source-code HTML preview **does not execute the page**; download the file and open it in a browser.

**Available controls:** Heather 1797 / proposed paper-sheet change / Collin 1818; desktop / 390px phone; reconstructed connections / narrated places. Chart locations are *not georeferenced*; red sequence markers occur only in the reading panel, not on the original scan.

**Review before any code:** What makes the paper change believable? Can you see the Plate → Carrol → Cape *change of direction* on the actual source? Does the printed original allow usable camera crops at 1440×900 and 390×844? How should a reader distinguish original printed routes, inferred joins, and Ahab's Ch. 44 graphite?
